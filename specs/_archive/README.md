# Archive

Specs that are finished, decided against, or retired. **Nothing here is open work** —
`../README.md` holds that, and it holds only that.

Kept rather than deleted for two reasons. A **WON'T-DO** is a decision: without the
record, the same idea gets proposed again in a month. And a retired rule explains code
that still exists — delete the rule and the code looks arbitrary.

Verdicts: **DONE** shipped · **WON'T-DO** decided against, with the reason · **RETIRED**
was binding doctrine, no longer is (the surviving rules live in `../../DOCTRINE.md`).

| 805 | **DONE** | [Sandbox batch: one process start for N runs](805-sandbox-batch.md) | Written and built the same day, 2026-08-11, off a measurement taken while sizing 774: `trx64cli` costs ~740 ms to start — ~650 ms of it eager machine init *before* argument parsing (a tiny binary from the same workspace starts in 86 ms; stripping made it worse, so not size). The C64RE depack bridge spawned a process per payload, so one proof project's 101 chunks meant ~75 seconds of pure startup for milliseconds of work. Two obvious fixes were both wrong: a scratch machine inside the daemon is two machines in one process (doctrine rule 2, and the module-global VIC/vice1541 state makes it unsafe, not merely disallowed), and re-implementing the run over individual RPC calls duplicates orchestration the CLI owns — seed/cart/disk, blob loads, ZP seeding, the `$01` config, an 11-byte entry stub the CLI builds, sentinel, caps, harvest ranges — and puts the two out of step the moment either changes. The cut was neither: one process start, N runs, the 787 scratch instance otherwise untouched. Each item runs on a fresh thread, not for parallelism (they are sequential) but because the core carries one thread-local — the IEC bus status arrays mirroring VICE's statics — that no machine constructor resets, so a batch item attaching a disk would have seen its predecessor's device flags. The bridge now builds a batch *spec* rather than an argv and the single-payload path is literally a batch of one, so the two cannot diverge. Measured: 20 runs 15.09 s → 0.83 s (18.1×) byte-identical; 10 payloads through the bridge cost 937 ms against 897 ms for one. Gate `e2e:805-sandbox-batch` 7/7. |
